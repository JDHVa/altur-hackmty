# Centinel Altur — consola

Front-end estático del detector humano/IA. Le pega al backend GPU en Modal.

**Antes de usar:** edita `index.html` y cambia `window.API_BASE` por la URL pública
de tu endpoint de Modal (la que imprime `modal deploy`), por ejemplo
`https://tu-workspace--altur-100-detect-web.modal.run`.
